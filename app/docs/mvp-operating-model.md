# lihiSMS Growth Console MVP

## Who it is for

Tony only. This is a single-operator internal growth console.

## What it optimizes

- Primary KPI: `email verified signup`
- Audience: `電商品牌`
- Landing page is treated as fixed for this version

## Core loop

1. Maintain a structured strategy library for use cases, benefits, proof, and templates.
2. Generate one batch at a time from `1 use case + 1~2 benefits`.
3. Produce exactly three creative variants for that angle.
4. Review assets manually and record approval or rejection reasons.
5. Create Facebook draft ads from approved assets only.
6. Publish manually.
7. Sync the core funnel and receive rule-based suggestions.

## Guardrails

- No automatic publishing
- No automatic budget changes
- No automatic audience changes
- No automatic execution of recommendations
- Optimization stays on the creative layer first

## Canonical metadata

- `icp`
- `use_case`
- `benefit_1`
- `benefit_2`
- `angle_id`
- `creative_version`
- `created_at`
